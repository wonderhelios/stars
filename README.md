# stars · 动量 alpha 研究台

一个单二进制的 Rust 服务，做一件事：**用 Hyperliquid 全宇宙历史数据验证横截面动量 alpha，并用纸交易确认执行成本后，再考虑上实盘。**

旧版（OKX/Binance/Hyperliquid 三平台信号扫描 + 1182 组参数实验室 + 执行回放 + 策略交接）已全部移除。研究结论：原「做空高资金费率 + 暴涨币」信号是负期望的裸空 beta；真正有信号的是**横截面动量**——买过去 14 天涨幅前 20% 的流动币，用等权篮子对冲。

## 三个页面

1. **回测**：选参数（回看天数 / 多头比例 / 最低成交额 / 对冲方式），一键跑横截面动量回测，看纯 alpha、Sharpe、t 统计、分年表现、成本敏感度、集中度。
2. **纸交易**：前向跑策略（每日再平衡），追踪策略净值 vs 等权基准，验证「真实成交成本 ≈ 回测假设」。
3. **上实盘清单**：逐项 GO/NO-GO，全部通过前不要上真金。

## 运行

```bash
cargo build --release
STARS_DB=/var/lib/stars/candles.sqlite STARS_PAPER=/var/lib/stars/paper.json ./target/release/stars
```

打开 `http://127.0.0.1:3000/`。首次启动会后台回填 Hyperliquid 全宇宙日线（约 5~15 分钟），期间回测按钮会提示数据不足，等状态栏显示「已缓存 N 币」即可。

## 回测方法（诚实性保证）

- **宇宙**：Hyperliquid 全部币（含退市币），修正幸存者偏差
- **流动性**：滚动 30 日成交额过滤（点时间、无前视），只在真实可交易的币上建仓
- **对冲**：等权篮子对冲，剥掉 beta，看纯 alpha
- **成本**：换手率 × 双边费率，报告净年化
- **结论**（3.2 年历史）：流动币（≥$5M）动量纯 alpha 约 **+0.22%/天，Sharpe 1.6，t≈2.5**，市场中性（与 BTC 相关性 ≈0），2024/2025/2026 均为正
