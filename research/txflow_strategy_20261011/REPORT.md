# TxFlow 可交易币池 × 币安行情：第一轮筛选

本轮完成，**没有候选通过上线标准**。限定 TxFlow 币池研究可行，但本次仅用币安现货日线做代理诊断。结果不能代表 TxFlow 永续实际收益，也不能据此证明 Hyper 优于 TxFlow。

## 范围与可复现性

81 个当前映射成立的加密资产，70,267 根日线；绩效区间 2024-02-15—2026-10-07（966 天）。每日满足历史成交额门槛的币平均约54个。只包含加密资产，不将股票或黄金混入同一横截面。

7种固定因子组合 × 1/3/4档调仓 =21个家族，全部相位56条路径，5种成本/延迟场景，共280条路径。全部登记于 attempts.json；参数事前写在 SPEC.md。资金统一$3,000、目标总名义敞口2.7倍，使用当前TxFlow数量步长与最小调仓阈值。研究未修改线上策略、配置或执行交易。

M=波动调整动量，L=低波动，V=成交量冲击。所有年度指标都来自连续账户对应区间，并非每年重新开始配置仓位。年化收益使用几何年化CAGR，Sharpe使用365日；不把年化成本比例直接从CAGR相减。

## 日线成交时点是主要不确定性

下表均扣除单边7.5bp（手续费4.5bp+滑点3bp），未扣实际资金费；属于代理回测。次日开盘模型假定日线收盘后立即按下一开盘成交，偏乐观；延后一天模型是24小时延迟压力，**不能将其等同于实际00:05成交**。两者并非实际绩效的严格上下界。

|组合（每日调仓）|次日开盘：全期Sharpe|次日开盘：全期CAGR|额外延后一天：全期Sharpe|额外延后一天：全期CAGR|
|---|---:|---:|---:|---:|
|原三因子 M+L+V|1.64|122.6%|1.34|83.3%|
|动量+量能 M+V|2.07|229.0%|1.58|127.9%|
|量能 V|1.66|155.7%|1.58|134.1%|

不能只看全期高收益。2026年截至10月7日的同口径结果：

|组合|次日开盘Sharpe / CAGR|额外延后一天Sharpe / CAGR|
|---|---:|---:|
|M+L+V|1.58 / 81.6%|-0.41 / -24.1%|
|M+V|1.79 / 135.1%|0.02 / -13.4%|
|V|2.10 / 183.4%|-0.10 / -19.9%|

这说明精确执行时点必须进一步核验，不能凭日线假设判断删掉低波动因子就会改善实盘。M+V在较乐观模型下全期最大回撤仍约52%，不是低风险高收益组合。

## 事前选型与统计检验

按冻结方案，主模型是额外延迟一天；只用2024年平均相位Sharpe选择，选中V/每日。其2025年Sharpe1.49低于基线2.08，2026年为-0.10；后段没有保持训练期优势，故否决。

主模型对基线的配对循环块bootstrap，15/30/60日块、各1999次、21家族maxT，取最保守结果：V/每日全期p_FWER=0.853，M+V/每日=0.818，均远大于0.05。后者2025年也未改善（1.99 vs 2.08）。本校正只覆盖本轮家族，不能消除过往研究和场景比较带来的搜索偏差。所有数据已用于既往研究；2025/2026仅历史分段验证，不是真正未见样本。次日开盘场景仅敏感性诊断，没有单独据其重新挑选赢家。

## 成本、相关性与执行缺口

主模型每日三因子年换手约624倍账户权益，成本折合年化日均权益46.8%；M+V约52.3%，V约68.3%。V在2026年的CAGR，在提高滑点至6bp时约-39.1%，在双边总名义敞口年扣3%资金费压力下约-25.8%。maker方案只是乐观参照，未建模成交和逆选择。

主模型全期每日收益相关性：M+V对三因子基线0.767，V对基线0.688；这是**币安代理基线**相关性，不是与Hyper实盘收益的相关性。全部候选相关性保存在correlations.csv。

记录了持仓价格漂移、数量取整、最小交易额、成本、名义敞口与净敞口。没有实现真实TxFlow顺序保证金准入、盘口部分成交和强平。本批将gross>3倍或绝对净敞口>10%权益标记为风险违例，不是假称交易所一定会拒绝或强平。

M+V/每日在次日开盘模型有69个风险违例日（主模型2日），基线分别3日/5日。错峰路径存在更多违例；例如M+V/4档主模型最差相位775日，不能直接部署。**实际加入风险约束后必须重跑，而不能保留未受约束的好看收益。** 各相位最小/最大Sharpe及指标见summary.csv，每条路径见metrics.csv。

其他不可省略的限制：

- 现货代理永续，缺实际资金费、基差与TxFlow成交深度；币安成交额不代表TxFlow容量。
- 用当前可交易币池回看历史，有幸存者偏差；缺历史TxFlow上市/退市时间与历史合约规则。
- 缺2023数据，未完成协议要求的2023—24 / 2025—26对照。
- 不存在“用杠杆改善Sharpe”的结论；所有方案使用同样初始权益和目标敞口。
