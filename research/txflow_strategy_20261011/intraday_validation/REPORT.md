# MV追加核验：5分钟成交代理 + 同账户风险约束

## 最近三个月的阶段结果（已被更长连续账户核验补充）

原81币候选池，2026年7—9月243份币安现货5分钟月度归档全部取得。每币每日抽取00:00、00:05、01:00开盘，单位按现有映射转换一次。日线用于生成前一日已完成信号，5分钟行情用于执行与持仓估值；不是用5分钟拟合新因子。

每次均从同一个$3000账户出发、目标总名义敞口2.7倍。保留2%调仓门槛，并在门槛处理后削减超限仓位，使调仓后总敞口<=2.7倍、绝对净敞口<=权益5%、按min(3,当前最大允许杠杆)估算初始保证金<=权益90%。取整和$10最小单额造成无法修复时，关闭可执行持仓；该回退规则是研究模型的一部分，**尚未实现到实盘，也不是原三因子历史结果的直接复现**。

## 稳定性与限制

- MV基础成本在00:00 / 00:05 / 01:00成交的收益分别44.35% / 45.93% / 22.93%，Sharpe3.14 / 3.24 / 1.84。5分钟延迟没有抹掉优势，延迟一小时明显削弱，不能据此认定任意时点可执行。
- 00:05基础成本两组合每日收益相关性0.649。7/15/30日配对循环块bootstrap中，MV相对MLV的Sharpe差最保守单边p=0.2235；7日块95%区间[-2.05,5.62]，未显著。21家族Bonferroni敏感性校正为1；这不覆盖历史所有搜索。
- 00:05基础成本MLV/MV分别65/56次风险修复、7/6次平仓回退。仅检查调仓后时点风险，无盘中保证金/强平/逐单成交模拟。两组合所有18场景调仓后均无定义内违例，不能据此声称实盘无风险。
- 成本提高后个别收益反而上升，因为权益变化会改变数量取整、2%交易门槛与平仓回退路径；不是“高手续费有利”。回退次数随成本改变，说明离散执行规则敏感，不应只比较最高结果。
- 7433个日线/5分钟开盘可比观测中32个有差异，最大0.382%，保留原始差异记录，不回写日线、不据此重选币。所有场景持仓缺价日和信号目标缺价日均为0。
- 币安现货代理TxFlow永续；无真实TxFlow资金费、盘口、历史上市和历史保证金规则，当前幸存币池问题仍在。TxFlow资金费请求网络失败，未使用猜测数据。

账本测试覆盖恒价只扣费、未来数据不影响此前收益和风险准入；原始档案摘要及抽样价格在data/，全部18路径登记于attempts.json，统计在metrics.csv与inference.csv。

结论：近期支持继续核验MV，但不足以晋级实盘。已登记追加上半年及连续1—9月测试，同样18场景，不修改因子、成本、风险规则或挑选执行时点。
