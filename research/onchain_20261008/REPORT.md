# 链上资金流验证：没有通过的候选

结论：本次没有可认定提高实盘 Sharpe 的新边际。40 个组合候选全部未通过统一 FWER 校正；即使统计通过，当前修订版历史也缺乏可得时点证据，不能取得上线资格。没有改动 trader.rs、没有发出交易。

## 数据与可得时点：硬限制
先读 docs/validation-protocol.md 与 src/trader.rs。仓库及工作目录搜索未找到 common.md，按前述五项协议执行。免费接口取得 USDT/USDC 独立供应量、USD pegged 稳定币总供应量、18 链 TVL、17 链稳定币历史；Cosmos 稳定币接口返回非 JSON，保留失败响应，不补造。原始 JSON、HTTP 响应头、SHA256 和抓取审计保留在 data/、api_audit.json。初次USDT下载不完整，压缩重试后完整解析。抓取为2026-10-07 UTC（本地10-08）。部分缓存首次请求时间在重试审计覆盖时丢失，已明确记录，文件mtime不是历史发布时间。
**免费接口只有数据时点，没有历史 first-seen / 发布时间 / 历史版本。** 本回测只对当前修订版作探索：score[i] 使用数据日期 i−2 或 i−7，i+1 日开盘执行，相当于从标记日期到执行至少3/8日。这是假设的滞后敏感性，不是证明当时可得。不能把“延迟几天”说成已消除前视偏差；基于真实抓取时间，所有旧数据本次才首次可证实可得，根本无法回测2023–26历史交易。
DefiLlama 维护者明确说明会追溯修正协议数据，新增/修订协议也会改变历史链 TVL：[维护者说明](https://github.com/DefiLlama/DefiLlama-Adapters/discussions/6593)。TVL 同时含价格变化与存取款，不能直接叫净资金流：[官方指标定义](https://enterprise.defillama.com/data-definitions)。减掉原生币涨幅也只是粗略价格调整，不能消除不同抵押资产价格组成。稳定币增发可能反映库存、支付用途或链间桥接，不等同场外风险资金买入；链份额变化不是逐笔迁移证据。稳定币历史也没有版本保证，不能假定永不修订。
Etherscan v2 对已知公开交易所地址的无 key 请求返回 `Missing/Invalid API Key`，原始响应保留。没有可用 key，也没有可靠全交易所地址标签、冷热钱包内部转账消除、跨链/多资产覆盖。因此**交易所净流入没有数据、没有测试结论**；单地址转账也不能代替交易所总净流入。未搜索或披露私人凭据。
本地 candles.sqlite 只含 candles、candles_h、oi_snapshots（534条）；OI不是链上资金流，不用作替代。

## 五项检验与口径
1. 调仓所有3个相位，报告平均Sharpe、SD、range与逐相位数值；14/30日是每日滚动回看窗口，没有额外起点相位。每日择时，无稀疏日历触发。无预注册离散度阈值，不事后挑阈值；基线早段离散明显，应另核对。
2. 日收益按共享日历、配对循环移动块bootstrap，4999次，15/30/60日块；不作事件朴素t检验，也不把重叠回看当独立样本。保留同期币、相位、候选依赖；市场预测同用块，下一日无多日持有重叠。
3. 次日UTC开盘为成交基准代理，全部按taker4.5bp+滑点3bp每次买卖名义扣费，终点统一清仓收费。无maker触价模型。maker1.5bp+3bp只作**乐观费用下界**：没有队列/条件成交与成交后不利价格路径，无法回答成交那批单是否好单，不能作为maker可实现收益。另有滑点6bp、缺价退出额外不利5%压力。
4. 对相位平均Sharpe差使用影响函数近似studentized maxT（72项统一族），同时覆盖40对基线、16对恒定敞口、16市场均值差；每个时期分别校正。不是精确有限样本检验，点态95%区间不是同时置信区间。通过规则要求全期和两子区间、三种块长都p<0.05，属交并门槛，没有挑选最优时期或块长。此族校正仅适用于本次40个固定配置，不能纠正未知的130+历史选择。
5. 全期/2023–24/2025–26、换手、执行成本、策略相关性、分数对已有动量的rank相关全部报告。**资金费缺完整历史，净收益仅扣执行成本，不能叫完整实盘净收益**；忽略最小订单、数量精度、资金容量、强平/拒单，缺价持仓假设按最后可见标记退出（并压力测试），这不能替代真实退市成交。
