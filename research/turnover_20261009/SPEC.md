# 预先固定的研究口径与判定（候选结果生成前写入）

基线：baseline.py 原 run 函数，cap5/open/fee0.0007，Sharpe 必须在 1.1293 ±0.00005 内；所有实验通过原引擎仅替换 target，诊断通过注入只读记录点。禁止 src 修改。

候选共 12 个：权重平滑 alpha={0.3,0.5,0.7}；波动自适应 q={0.60,0.75,0.90} × alpha={0.3,0.5}（低波 alpha=1）；排名滞回 exit={0.25,0.30,0.40}。
平滑使用上日平滑目标；新币旧权重为零；退出币逐步衰减，丧失资格币直接清零；每次净绝对权重归一化为 1。
自适应信号：等权合格市场每日收益的过去20日波动；阈值为之前最多252日、至少60日波动分位数。信息截至信号日收盘，下日开盘成交。
滞回在三个因子的各个多/空袖套分别执行：原持仓仍在当侧 exit 分位以内则保留（若当前 k/N > exit，以 k/N 为准），否则退出；席位不足按当前排名补齐，每侧仍持有 k 个；跨越另一侧必须先退出。净合并后归一化。

全部候选每日调仓，只有一个日历相位；不把滚动20日窗口虚构成20个调仓相位。另做0/1/2日启动偏移并在共同日期评估，报告均值、标准差、配对 delta 跨起点极差；采用均值作为主表。基线同样偏移并配对。不得因启动结果筛选。
显著性：配对 Sharpe 差的影响函数、中心化 circular moving-block bootstrap，B=4999，块长20日；另测10/40日。12候选共同 maxT FWER，单侧正改进；p=(1+超过次数)/(B+1)。按共同日期、起点平均收益计算检验。
“可用”：三种块长 p_fwer 均<0.05；两子区间2023-24/2025-26 Sharpe均为正且均改善；全样本正改进大于配对启动 delta 的极差；成本0.00075下两子区间仍均改善；无缺失持仓报价。
“低成本改进”：全样本 Sharpe 下降不超过0.10、固定回撤期2024-03-05至2024-10-15（含两端）换手≤基线的2/3；单列，不赋予可用资格，也不要求显著收益提升。
成本：主表0.0007；完整重跑taker0.00045、maker理想下界0.00015、taker+滑点0.00075。maker仅成本敏感性，不声称可成交。
年化净利明确同时列算术年化与CAGR；年成本=平均成交名义/交易前净值×费率×365。

归因分组：固定回撤前、期间、之后；目标币净名单进入/退出/反手/同向权重变化/目标不变为互斥成交贡献。另报告实际持仓方向同向/反手等，避免把因子袖套变化与净交易混淆。
相关矩阵：日换手、截面收益波动、20日市场波动、20日组合波动、共同合格币的三个因子平均绝对百分位排名变化、合格币数；报告全样本与固定回撤期，Pearson及Spearman落盘。
门槛：逐笔诊断10美元、2%调仓带与精度；另关闭10美元门槛完整重跑作对照，不加入候选搜索。
研究为样本内探索，FWER只覆盖此次12候选，不覆盖历史130+方向；不作实盘更改。
